## 🌐 About ByteShelf

**ByteShelf is a free online library dedicated to programming and computer science.**

Whether you're a beginner learning your first programming language or an experienced developer looking to expand your knowledge, ByteShelf helps you discover useful learning resources in one place.

Explore a wide collection of programming ebooks, technical books, online courses, tutorials, and podcasts covering different technologies, programming languages, and development fields.

Our goal is simple: **make programming knowledge easier to discover and accessible to everyone.**

## ✨ Main Features

- 📚 **Programming Library:** Discover thousands of programming-related ebooks, books, courses, tutorials, and podcasts.
- 🔎 **Explore & Discover:** Browse resources by programming language, technology, category, and subject.
- 🌍 **Multilingual Experience:** Explore resources across 53 languages and access an interface adapted to your preferred language.
- 🏷️ **Technology Categories:** Find resources covering Python, JavaScript, Java, C++, C#, Rust, Go, PHP, SQL, React, and many more technologies.
- 📱 **Responsive Design:** Enjoy a consistent experience on smartphones, tablets, laptops, desktops, and large screens.
- 🔐 **User Authentication:** Secure account access powered by Clerk.
- 🌐 **Automatic Language Detection:** The website automatically selects an appropriate interface language based on browser preferences, with additional detection options.
- ↔️ **RTL Support:** Right-to-left layouts for Arabic, Hebrew, Persian, and Urdu.

## 🚀 Getting Started

### Requirements

- [Node.js](https://nodejs.org/) v18 or newer
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/sidounasser/ByteShelf.git

# Enter the project directory
cd ByteShelf

# Install dependencies
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

`http://localhost:5500`

### Build for production

```bash
npm run build
```
